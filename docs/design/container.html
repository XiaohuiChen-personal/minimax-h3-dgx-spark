04

Dockerfile contract

  1. FROM official NVIDIA PyTorch, linux/arm64, CUDA 13. Record the tag.
  2. Image Python must see the GPU. Never the Spark’s system Python.
  3. Clone ComfyUI after commit bdcb886a. Record the SHA.
  4. Install SageAttention 2.2.0 for this chip. Install Sol-Attn (triton_ref) and H3 FirstBlockCache (H3 Safe).
  5. Copy workflows and scripts. EXPOSE 8188.
  6. Entrypoint: check weight files, then start ComfyUI with the flags below. Do not require a license env flag (D-13).
python main.py --listen 0.0.0.0 --port 8188 \
  --fast fp8_matrix_mult --disable-pinned-memory

# forbidden: --lowvram --novram --use-sage-attention
05

Start it on a Spark

Do this on the DGX Spark, not on a laptop. The Dockerfile is not in the repo yet — this is the recipe the next implementation step follows.

  1. Confirm the box. uname -m is aarch64. nvidia-smi sees the GB10. Docker can use --gpus all.
  2. Download weights into ~/h3-weights (helper script, or by hand from Comfy-Org). Also create ~/h3-output and ~/h3-data.
  3. Build. cd deploy && docker compose build. If the image is ~50 GiB, weights were baked in — that is a bug.
  4. Start once. docker compose up -d. Wait for port 8188. Leave it up. Do not restart per video.
  5. Smoke test the 5.17 s workflow via scripts/submit-prompt.sh. If the mp4 has video and stereo audio, the 8.00 s default is allowed.
  6. Stop only when you mean to free the GPU. docker compose down unloads the models.
docker run --gpus all --name h3-comfy \
  -p 8188:8188 \
  -v "$HOME/h3-weights:/opt/ComfyUI/models:ro" \
  -v "$HOME/h3-output:/opt/ComfyUI/output" \
  -v "$HOME/h3-data:/data:ro" \
  h3-spark:local

Prefer Compose so the mounts stay consistent. Image name h3-spark:local. Port 8188.

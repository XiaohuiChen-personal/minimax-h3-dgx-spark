An implementing agent treats these as “build this.” Do not invent a fourth stack. Evidence lives in the research briefing.

00

How to read a status

  • Adopted — build it unless new measurements reverse it.
  • Adopted for implementation — same default; the first real clip can still reverse it.
  • Superseded — kept so we do not repeat the mistake.

D-04

adopted

Stock ComfyUI SPAN after decode. About 6× faster than Real-ESRGAN on this Spark.
Not
Real-ESRGAN, NVIDIA VSR (no ARM), SeedVR2.
D-05

Generate 960×544, then 2×

adopted for implementation

Multiples of 32. Exact 2.00× to 1920×1088, crop to 1080p. Portrait: 544×960. Reverse if 2× looks soft — then 1216×672, not native 720p.

D-06

Eight steps when there is talking

adopted for implementation

8 steps for speech. 4 steps only for silent seed-hunting. ComfyUI newer than 2026-08-06 (ModelSamplingAV). Shifts 6/3 with Turbo, 12/3 without. Ask the sampler for 9 sigma points on an “8-step” LoRA.

D-07

Default length 8.00 s

adopted

Smoke test 5.17 s (124 frames). Everyday 8.00 s (192). Longer stories: stitch 8 s shots. “10 seconds” → 10.13 s or refuse.

D-08

SSH + agent, one job at a time

adopted — product

Leave ComfyUI up. The agent fills a locked workflow. A second request queues. See the operator page.

D-09

NVIDIA GPU PyTorch base

adopted

FROM official NVIDIA PyTorch, linux/arm64, CUDA 13. System Python is CPU-only torch — do not start there. Record the NGC tag at implement time.

D-10

Weights on the host

adopted

Never bake MiniMax files into the image. A download script fills ~/h3-weights. Missing files → entrypoint exits with a list.

D-11

Pin ComfyUI after the two-clock fix

adopted

Commit newer than bdcb886a (2026-08-06). Record comfyui.git_sha on the image. Do not float on master.

D-12

First image includes the speed-ups

adopted for implementation

Sage 2.2, Sol-Attn triton_ref, FirstBlockCache H3 Safe, Turbo 8-step, SPAN. Never EasyCache, SA3, flex_attention, Turbo-SLA+Sol-Attn, or --lowvram. Details: optimizations.

D-13

Do not gate start on a license flag

adopted

The operator accepts the Community License risk. Start if the weight files are present. Do not require H3_LICENSE_ACK or an interactive prompt.

D-14

Compose names and host folders

adopted

deploy/compose.yaml, image h3-spark:local, weights ~/h3-weights, output ~/h3-output, pictures ~/h3-data, port 8188.

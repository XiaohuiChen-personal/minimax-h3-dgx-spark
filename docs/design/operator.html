DesignD-08 · adoptedProduct end goal

SSH in, ask the agent, get an mp4

After deploy, Cursor or Claude on this Spark submits a predefined workflow to a long-lived ComfyUI. One GPU job at a time is the accepted local limit.

01

The product

Not vLLM chat. Not a new engine per request. One server, queued jobs, locked DAGs.

02

Operator steps

ComfyUI is already up. The agent only fills free fields and waits.

  1. Leave ComfyUI running. Start it once. Do not restart per video.
  2. SSH into the Spark and open Cursor or Claude on that machine.
  3. Ask for a generate against the default Ref2VA 8.00 s graph (or 5.17 / 15.08). Text-only uses the FL2VA pair.
  4. The agent changes only free fields (prompt, seed, filename, optional --ref-image host files) and POSTs to /prompt after POST /upload/image.
  5. It polls /history/<prompt_id> for minutes, then returns the host path under ~/h3-output (SaveVideo suffix, e.g. default-8s_00001_.mp4).
03

What one generation does

The JSON is assembly. The denoising loop lives inside one sampler node.

06

Limits — accepted

One GPU job at a time

This is a local box. A second POST /prompt waits in ComfyUI’s queue. That is the product, not a defect.

  • Warm start. Do not start or restart ComfyUI per video.
  • Wall-clock. A warm 8.00 s job is minutes. Agents must poll or background-wait.
  • No multi-user serving. SSH-local only. vLLM-Omni is a later D-01 option.
  • License. Excluded-territory users (EU, UK, Republic of Korea, United States) request approval at platform.minimax.io/h3-license. Others do not. Do not block a generate on an ack flag (D-13).
07

What the agent must not do

A normal generate is a parameter patch, not a new install or a new graph.

  • Download weights or embed tokens in the graph
  • Enable EasyCache, SageAttention 3, a blind --use-sage-attention flag, Sol-Attn flex_attention, Turbo-SLA on top of Sol-Attn, or --lowvram
  • Change canvas, steps, or length except to another legal pair (5.17 / 8.00 / 10.13 / 15.08 s)
  • Start or restart ComfyUI for a normal generate
  • Treat <Picture N> as a substitute for --ref-image uploads, or write those tags on FL2VA
  • Treat a 3-view sheet as first_frame
  • Strap the FL2V 8-step LoRA onto Ref2VA, or invent 15.00 / 15.04 lengths
  • Start a second ComfyUI because the first job is “taking too long”

HTTP contract

The submit script talks to a server that is already up. It does not start Docker.

BusyAnother submit queues. Do not spawn a second server
